\f0\b \cf2 \cb3 \strokec2 ## What this project measures
\f1\b0 \cf4 \cb1 \strokec4 \
\
\pard\pardeftab720\partightenfactor0
\cf4 \cb3 Given a validation workbook in which each case has been annotated by both a human and the\cb1 \
\cb3 AI summarizer (against the underlying source document), the pipeline:\cb1 \
\
\pard\pardeftab720\partightenfactor0
\cf6 \cb3 \strokec6 1.\cf4 \strokec4  Loads and cleans the workbook (coercing placeholder strings to \cf2 \strokec2 `NaN`\cf4 \strokec4 , dropping only rows\cb1 \
\pard\pardeftab720\partightenfactor0
\cf4 \cb3    absent from the source so accuracy is scored only over findings that actually exist).\cb1 \
\pard\pardeftab720\partightenfactor0
\cf6 \cb3 \strokec6 2.\cf4 \strokec4  Computes per-element accuracy for human and AI annotators across 14 clinical elements.\cb1 \
\cf6 \cb3 \strokec6 3.\cf4 \strokec4  Compares human vs. AI per element with McNemar's test and Agresti-Coull 95% confidence\cb1 \
\pard\pardeftab720\partightenfactor0
\cf4 \cb3    intervals.\cb1 \
\pard\pardeftab720\partightenfactor0
\cf6 \cb3 \strokec6 4.\cf4 \strokec4  Renders a color-coded \cf2 \strokec2 `great_tables`\cf4 \strokec4  summary table and a grouped bar chart, and exports\cb1 \
\pard\pardeftab720\partightenfactor0
\cf4 \cb3    them to \cf2 \strokec2 `outputs/`\cf4 \strokec4 .\cb1 \
\
\cb3 A separate figure script (\cf2 \strokec2 `src/make_figures.py`\cf4 \strokec4 ) renders publication-style figures\cb1 \
\cb3 (paired accuracy dumbbell + difference forest, missingness panels, supplemental grouped\cb1 \
\cb3 bar) to \cf2 \strokec2 `outputs/figures/`\cf4 \strokec4 . A companion utility classifies the missingness mechanism\cb1 \
\cb3 (MCAR / MAR / MNAR) to assess whether missing annotations bias the accuracy estimates.\cb1 \
\
\pard\pardeftab720\partightenfactor0

\f0\b \cf2 \cb3 \strokec2 ## What this project is not
\f1\b0 \cf4 \cb1 \strokec4 \
\
\pard\pardeftab720\partightenfactor0
\cf4 \cb3 This is an offline evaluation and analysis project, not a production summarization service.\cb1 \
\cb3 It does not call or host the LLM. It consumes a pre-built validation spreadsheet in which\cb1 \
\cb3 AI and human annotations have already been recorded.\cb1 \
\
