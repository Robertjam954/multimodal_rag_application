\f0\b \cf2 \cb3 \strokec2 ### Column naming
\f1\b0 \cf4 \cb1 \strokec4 \
\
\pard\pardeftab720\partightenfactor0
\cf4 \cb3 Preserve the \cf2 \strokec2 `<element>_status_\{source,human,ai\}`\cf4 \strokec4  schema. Accuracy is always:\cb1 \
\
\cb3 ```\cb1 \
\cb3 accurate-count (source==1 AND annotator==1) / source-present count (source==1)\cb1 \
\cb3 ```\cb1 \
\
\cb3 When adding new elements, follow this convention and add all three columns\cb1 \
\cb3 (\cf2 \strokec2 `_source`\cf4 \strokec4 , \cf2 \strokec2 `_human`\cf4 \strokec4 , \cf2 \strokec2 `_ai`\cf4 \strokec4 ).\cb1 \
\
\pard\pardeftab720\partightenfactor0

\f0\b \cf2 \cb3 \strokec2 ### Statistics
\f1\b0 \cf4 \cb1 \strokec4 \
\
\pard\pardeftab720\partightenfactor0
\cf5 \cb3 \strokec5 -\cf4 \strokec4  Pair accuracy proportions with Agresti-Coull (adjusted Wald) 95% confidence intervals.\cb1 \
\cf5 \cb3 \strokec5 -\cf4 \strokec4  Use McNemar's test for paired human-vs-AI comparisons; use the exact variant for small\cb1 \
\pard\pardeftab720\partightenfactor0
\cf4 \cb3   discordant counts (< 25).\cb1 \
\pard\pardeftab720\partightenfactor0
\cf5 \cb3 \strokec5 -\cf4 \strokec4  Do not substitute two-proportion z-tests or chi-squared tests for paired data.\cb1 \
\
\pard\pardeftab720\partightenfactor0

\f0\b \cf2 \cb3 \strokec2 ### Missing data
\f1\b0 \cf4 \cb1 \strokec4 \
\

\cf5 \cb3 \strokec5 -\cf4 \strokec4  Coerce placeholder strings (\cf2 \strokec2 `na`\cf4 \strokec4 , \cf2 \strokec2 `NA`\cf4 \strokec4 , \cf2 \strokec2 `N/A`\cf4 \strokec4 ) to \cf2 \strokec2 `NaN`\cf4 \strokec4  before any analysis.\cb1 \

\cf5 \cb3 \strokec5 -\cf4 \strokec4  Use the missingness utility to justify how missing annotations are handled.\cb1 \
\
\pard\pardeftab720\partightenfactor0
